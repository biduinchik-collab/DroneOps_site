# NORA Exploded View Animation

Files:
- nora_exploded_animation.html — standalone interactive HTML animation.
- nora_exploded_preview.gif — GIF preview of the animation.
- assets/*.png — extracted transparent line-art layers from the supplied PDF render.

Notes:
- This is a 2D / pseudo-3D technical animation built from PDF renders, not a native 3D model.
- For a production-grade 3D animation, use a real .GLB/.OBJ/.FBX model and animate it in Blender/Three.js.
- The current visual direction is dark aerospace / tactical technical schematic.
